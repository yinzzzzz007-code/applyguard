# ApplyGuard 演示脚本

视频使用虚构的 Career Vault 和离线规则工作流；画面来自本机运行的前端。预录阻断场景会在页面顶部明确标出，模拟 ATS 不是真实招聘网站，也不会提交申请。

| 顺序 | 操作／画面 | 解说要点 |
| --- | --- | --- |
| 1 | 经历库 | 查看经历、陈述和证据；表单修改只保存在浏览器会话。 |
| 2 | JD 输入与工作流结果 | 输入岗位说明并运行离线规则工作流，实际调用本机后端。 |
| 3 | 证据匹配 | 看原文高亮、匹配强弱和证据来源。 |
| 4 | 简历审查 | 看被选入与未选入的理由；手动加入不等于核验通过。 |
| 5 | 陈述核验 | 查看状态、原因、不受支持片段及证据。 |
| 6 | 网申模拟 | 展示字段映射、整体风险和需要本人确认的字段。 |
| 7 | 人工确认 | 确认后只生成本地演示结果；没有真实投递。 |
| 8 | 申请历史 | 查看本浏览器的模拟确认记录；后端审计尚未持久化。 |
| 9 | 预录阻断 | 展示不受支持的 CUDA 片段、拒绝操作、整单阻断与复制禁用。 |

录制时不要把模型密钥、真实简历、真实招聘账号或个人身份信息放进画面。演示视频是界面走查，不是可用性研究结果。
