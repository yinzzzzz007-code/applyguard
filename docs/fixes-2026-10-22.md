# 2026-10-22 核验、证据与导出修复交接

基于 main `e76e50d681b48cdfecc5809d23d6445610b8da4a`。本次修复对应 10 月 20 日本机运行检查中确认的五个问题，不需要模型 Key 即可验证。

## 行为变化

1. 手动加入的句子先保持阻断和“待重新核验”，不能靠“确认保留”绕过。陈述核验页新增“重新核验并更新风险”，后端重新读取候选人原文证据，忽略客户端伪造的状态、分数和 Evidence ID，再计算风险与模拟字段。未知或无原件的句子保持 BLOCKED；排除它后可重新核验其他句子。
2. 本地证据只有在已人工核对、原件哈希未改变、关联未拒绝/过期、原文明确支持完整句子时才返回支持。不相关语句、反向表述和额外指标不会因为“没找到奖项冲突”就变成 VERIFIED。当前支持判断采用保守的原句比较及窄范围奖项模板，可能拒绝合理改写；这种情况须补原文支持，不能直接提升状态。
3. 静态资源解析会规范化路径，并确认真实文件仍在静态根目录内。原始/编码 `..` 和指向外部的符号链接被拒绝。CORS 同时改为解析真实 loopback origin，拒绝伪装成 localhost 的凭据 URL。预录资源可在后端构建模式下读取。
4. 本机经历按稳定目标 ID 接到 Evidence Workspace 的有效关联。只有受支持原文中明确出现的技能参与匹配；不会把所有草稿标成 VERIFIED。模拟 ATS 摘要由本次选择的句子生成，不再固定引用 `claim_python_api`。未核实与缺证据归为待补充，不再等同于明确冲突；显式空草稿不会退回演示种子。
5. PDF 导入默认 `offline`。只有页面明确选择模型抽取，后端才会请求配置的服务商，并提示正文/文件名发送范围与费用。模型输出出现原文和本地抽取都不支持的字段时回退本地规则。

修改 JD、草稿内容或本机证据后，界面会清除旧流程或标记待重核验，同时清除旧确认。复制或最终模拟确认前，还会重新询问后端；如果原件在另一客户端被撤销、内容改变或服务不可用，就停止导出。这仍是本地模拟，不会执行真实招聘网站投递。

## 给 D 的接口接法

新增 `POST /api/v1/workflow/reverify`：

```json
{
  "candidate_id": "cand_demo_001",
  "application_id": "app_demo_001",
  "jd_text": "Backend Developer requires Python and automated tests.",
  "claims": [{"claim_id": "claim_example", "text": "A sentence to recheck."}],
  "resume_draft": {"candidateId": "cand_demo_001", "projects": []}
}
```

示例中的空草稿会被拒绝；实际请求须传当前真实编辑的草稿，或在演示种子模式下省略 `resume_draft`。最多 20 句，每句不超过 420 字符。请求仅发送 Claim ID 和文字，不能指定受信任的核验状态。后端返回更新后的 `resume_claims`、`claim_verification`、`evidence_match`、`ats_form_mapping`、`field_controls`、`risk_result`、`human_confirmation`、九步 `step_trace` 和审计记录。原有 JSON Schema 不变；无引用的被阻断编辑草稿属于额外的 UI 草稿结构，不可作为符合冻结 Resume Claim Schema 的已选结果使用。

工作流响应增加可选 `requires_reverification` 和 `evidence_sources`。本机原件的 `evloc_*` 在冻结 Vault 契约中表示为 `ev_local_*`，`source_reference` 保存 `local-evidence://evloc_*`；界面查原件时转换回真实本机 ID。这个命名适配不表示外部鉴定，90% 支持分也不是校准后的真值概率。

`POST /api/v1/resume/parse` 新增可选 `parse_mode: "offline" | "dynamic"`，省略时永远是 offline，Key 存在也不会自动调用。旧客户端无需改参数即可默认保护本地解析。

模型仍默认 `gpt-4o-mini` 和最多输出 2048 tokens；这是低成本测试默认值，继续支持通过 `APPLYGUARD_AI_MODEL` / `APPLYGUARD_AI_MAX_TOKENS` 换服务商支持的模型及上限。模型更换不解除证据检查。服务会读取本机 `.env`，不要提交真实 Key。

## 边界

原文比较是保守基线，不提供通用自然语言事实证明；OCR 真伪、私人材料真实性仍需人工判断。本地服务面向单用户，未新增多用户认证、永久申请历史或真实 ATS 自动投递。SAG 仍为可选辅助信号，未借这次修复宣称准确率提升。
