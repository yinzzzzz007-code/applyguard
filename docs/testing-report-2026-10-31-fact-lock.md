# 事实锁定与局部润色实验报告

日期：2026-10-31（北京时间）。本轮先做离线试验；没有重新生成模型文本或调用付费 API。

## 变更

在已有 SAG＋原子核验流程中，润色前建立仅含已判支持且有当前原文引用的事实清单：
原子事实、连续原文、来源 ID、SHA256 和版本必须相符。
清单随当前请求提供给润色模型。润色建议返回后，独立检查原句中已核验的
限定条件、数字与单位、技术、人物与技术的归属及明确负责人。
发现丢失或错配则拒绝采用建议，保留原句与原因，继续走现有原子核验。
原句本身证据不足时，不把它锁成“真事实”；旧句仍按原流程核验。

实现位于 backend/services/fact_lock.py，接入点为
backend/services/atomic_verifier.py。模型仍提出完整句子，程序对高风险变化设闸；
这次原型尚未把模型输出格式改成只能组合事实片段。
