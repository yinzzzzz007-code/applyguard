# 空白演示工作区验收 · 2026-11-24

## 录制操作

1. 打开本机录制入口 `http://127.0.0.1:8031/`。从“选择简历”开始，识别后导入经历库，核对后保存。
2. 录制公开 GitHub 检索时，打开“证明材料 → 从 GitHub 选择材料”，填写用户名或公开邮箱，核对账号，选择仓库并固定版本，然后点击“确认读取此版本 README”。公开邮箱查不到时可单用用户名。
3. 演示本地 Agent 时，展开“连接 DeepSeek Harness”，选择文件夹、填写任务、选择外发规则，再授权并运行配对。安装检测成功后仍要完成授权与配对。候选片段由用户确认后入库。
4. 选定岗位后审查当前正文，生成润色并对照改动。在“陈述核验 → 材料与核验明细”查看正文位置和材料原文。没有可用材料时可补原件，也可直接进入个人稿。
5. 需要快速完成时，在简历审查或陈述核验点击“跳过核验，导出个人稿”，核对最终文字、勾选并下载。也可点“用当前正文准备面试”，核对发送内容，生成题单后逐题回答、查看评分与追问，最后复练弱项。

## CLI 与日志

均从项目根目录运行。以下路径用参数传入，完整简历、证书、模型密钥及原始引文只在本机处理或按用户授权发送。公开报告只列统计结果。

```powershell
python scripts/start_recording_workspace.py --port 8031 --workspace <独立数据目录> --cache <独立NTFS缓存> --cloud
python scripts/replay_evidence_review.py --workspace <尚不存在的QA目录> --cache <NTFS缓存> --cv <简历PDF> --certificate <证书原图> --transcription <核对后的证书JSON> --foreign-readme <另一个项目的README>

python -m unittest discover -s tests
npm --prefix frontend run smoke
npm --prefix frontend run build

node scripts/check_review_shortcuts.cjs <独立课堂测试地址> <结果JSON>
```

浏览器检查需要 Node 可解析 Playwright 及本机 Edge。最后一个命令只对专门的课堂测试工作区运行。转录 JSON 包含原图 `sha256` 和由材料导入器接受的 `lines`。模型密钥在隐藏输入框输入。运行报告和逐项记录分别位于 QA 目录的 `report.json` 和 `local/verification-runs/`，含原文的产物不要用于公开演示。个人稿附带的审核记录可单独下载。

ASu 两个技能固定于同一提交 `d27fd2a3864c48472a5c8ed942410098ba9cd35f`，后端校验随项目保存的文件哈希。[ASu 面试技能](https://github.com/Hisn00w/ASu-skills/blob/d27fd2a3864c48472a5c8ed942410098ba9cd35f/skills/interview/SKILL.md)
