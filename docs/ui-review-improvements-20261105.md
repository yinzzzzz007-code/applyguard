# 2026-11-05 UI 两轮调整

基于 `feature/review-workbench-20261105` 的 `35c9dd3`，本地工作分支为 `feature/ui-review-improvements-20261105`。

## 完成的改动

- 审核页完整展示正文；优先三处用于定位，不再隐藏其余草稿。右侧展示当前句的建议、差异和依据；添加与管理内容归入折叠区。
- 润色改为先预览、再采用。即使服务端已将建议写入响应正文，客户端也保留当前正文，仅存为待采用建议。采用、编辑、撤销都不会自动授予材料通过或网申权限。
- 未保存输入提升至申请级状态，切换页面后保留。暂存输入、岗位、当前正文与上下文存入带版本的 sessionStorage；刷新恢复时撤销旧核验与填表权限。暂存范围是同一浏览器标签页，关闭标签页后不保证恢复。存储失败有提示。
- 存在未保存输入时，禁止润色、核验与导出；返回岗位页也不能静默重新分析并替换当前草稿。退出/刷新有未保存内容时触发浏览器提醒。
- 审核页主操作为检查并导出个人草稿；继续核验并准备网申是独立次级路径。导出前直接展示正文，说明个人草稿不等于核验通过。
- 岗位分析提供一个主按钮和解析方式选择；连接/调试信息折叠。相关度说明与材料可信度、录用概率区分。
- 材料检查与用户选择用不同标签表达。正文增大字号，移动端先显示草稿，工具可折叠，底栏不再覆盖内容。

## 第二轮：导航与资料准备流程

- 导航按“我的资料 / 目标岗位 / 审核草稿 / 导出与记录”分组。“证明材料”与经历库一起进入主导航，原有页面仍可访问。取消用访问顺序锁住导航，页面内的核验和导出条件继续生效。
- 证明材料页分为“材料库”和“经历关联”。没有文件时突出导入；从经历库的“保存并补充证明材料”始终进入材料库。已有文件的普通入口可先显示关联准备进度。两个面板保留在页面状态中，切换不丢失选中的材料、识别文字视图或待导入文件；当前标签记录在 URL 中，刷新可恢复。
- 保留原件预览、识别文字、字段核对，以及经历与材料并排核对。材料深链接进入材料库，切换标签保留带入的经历/材料参数；标签支持方向键、Home 和 End。
- 自定义 Agent 连接收进高级功能。手动添加文件即可开始，不要求先配置外部工具。
- 全局重复展示的说明移入“使用帮助”；首页仅保留可收起的简短提示。帮助页的 24 秒动画由用户展开后才加载，普通工作页面不加载该动画模块。
- 经历库主表单突出姓名、联系方式、项目与实习；性别、出生日期、民族、政治面貌、证件和户籍信息移到选填折叠区，已有值保留。核心资料准备度不再依赖这些选填信息或获奖数量；准备度是提示，不是保存门槛。
- 保存成功后才进入补材料。保存失败保留页面和输入；请求期间的新输入不会被旧响应覆盖，必须再保存才能继续。未保存经历切换页面回来继续保留，首次保存前也适用。
