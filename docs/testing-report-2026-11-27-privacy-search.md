# 本地隐私识别与并行材料检索验证（2026-11-27）

基线为 `11.25完整EXE版本` 的 `ebff3fb`；报告覆盖工作区未提交修改。结果是指定用例的运行记录，不是整份简历的准确率或生产可用性结论。

## 本地隐私模型

- 模型：`CheezOne/pii-detector-chinese-japanese-korean-english-small`，固定 revision `333854f6b01cbf265590c5f34ddf7b97f8d6365f`；ONNX INT8 权重和 tokenizer 已按 SHA-256 校验。模型和数据来源许可见 `THIRD_PARTY_NOTICES.md`。
- 命令：`python -m unittest tests.test_privacy_ner_live -v`。5 项通过，使用虚构姓名、数字和项目描述；包括 10 种姓名上下文及 1 个跨片段姓名案例、非人名文本、两层占位符和冲突引用恢复。
- 开发时观察到无标签姓名及分段边界漏检，加入保守姓名规则后上述用例通过。模型和规则仍可能漏检或误检；样本小且用于调试，不能据此计算总体准确率。
- 本轮额外人工执行 10 条虚构无个人信息句子，均未产生本地模型检测片段；这不是独立的误报率评估。

## 并行检索、预览和冲突提示

- `tests.test_harness_autostart` 使用线程屏障和模拟 Harness 进程，检查三个任务同时运行、会话目录不同、授权一致，以及个别任务失败时显示部分完成；这不是一次真实云端三代理运行。
- `tests.test_outbound_privacy` 检查并行检索时预览排队、用户未勾选的片段不返回、撤销和超时停止回传、自动概括只使用允许外发的片段。
- `tests.test_harness_conflicts` 使用模拟模型输出检查双侧引文必须匹配本地原文、无效来源不显示为冲突、来源文件变更可检测，以及取消前不发起模型请求；不衡量真实模型识别冲突的准确率。
- `tests.test_agent_mcp` 用真实本机 MCP 协议和虚构材料检查搜索等待用户确认；未调用云模型。
- 关闭可选本地模型、使用本机回环端口的后端回归运行 107 项，其中 1 项真实 OCR 测试因依赖条件跳过，其余通过。模型单独按上述命令实际运行，不应把关闭模型的回归计为模型准确性验证。
- 前端构建通过。`scripts/agent_disclosure_browser_smoke.cjs` 在无头 Edge 和模拟接口下检查计划、三任务设置、默认未勾选、片段选择和冲突提示；未启动真实云模型。

## 独立桌面版自检

- 在 `output/codex-build-privacy-search/dist/ApplyGuard.exe` 生成独立构建，没有覆盖原有桌面版。
- `--check-privacy` 退出码为 0：随包模型可用，合成姓名被替换，测试数字保留。
- `--check-backend` 退出码为 0，后端、Harness 模块、MCP、SAG、OCR 和 ONNX Runtime 等导入检查通过。这是启动及依赖检查，不代表完成真实云端或完整用户流程验收。
