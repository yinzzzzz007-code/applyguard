# 线下过程照片：独立同意模板

这是**可选项**。不拍照仍可参加问卷或访谈。默认拍参与者背影、手部与只显示虚构资料的问卷/流程卡；不要把拍脸作为默认。拍到脸、工牌、聊天通知、真实简历或 ATS 页面时，照片可能识别个人，不能称作匿名数据。事后打码不能代替事前同意。

研究者先说明：照片仅用于证明课程项目确实进行了线下研究，以及课程 Proposal、Final Presentation 或课程报告中的过程展示；研究小组内部可访问原始照片。公开展示前必须遮盖脸部及其他可识别信息。原始照片存放在受限目录，**不放进 Git 仓库或公开网盘**；去标识版经另一名组员复核后，尽快删除原始照片。若学校/课程对可识别照片有更严格的书面授权要求，以其要求为准。

## 参与者选择（拍摄前逐项征求；均默认为“不同意”）

- 参与者匿名编号：`P__`；日期：`YYYY-MM-DD`。
- A. 我同意研究者拍摄**不含可识别面部**的背影/手部/场景过程照片：`同意` / `不同意`。
- B. 我另行同意研究者拍摄**可能拍到面部**的过程照片，仅供小组私下制作去标识版本：`同意` / `不同意`。
- C. 我同意**经遮盖脸、姓名、屏幕私人内容等处理后的照片**用于课程课堂展示和报告：`同意` / `不同意`。
- D. 我同意上述去标识照片出现在**公开传播**的项目页面或公开幻灯片：`同意` / `不同意`。

只有 A 同意时才可拍不露脸过程照；只有 B 同意时才可拍可能露脸的原始照。C、D 仅授权相应的**使用方式**，不能替代 A/B 的拍摄同意。任何一项不同意都不影响研究参与。照片若有旁人入镜，需避开、裁切，或另取得其同意；无法处理就不使用。

同意记录方式：参与者在单独表单上主动勾选；如学校要求签署可识别照片授权，可在**与匿名回答隔离保存**的纸面表格上签署，不上传仓库。研究者记录表单版本、时间和 P 编号，不在公开材料放签名。可在课程展示前通过 P 编号联系研究者撤回尚未公开的照片授权；先说明匿名问卷回答若无法重新识别，可能无法定向删除。

## 拍摄与发布核对

- [ ] 拍前取得对应 A/B 同意，拍后再次确认照片内容；不在私人简历、通知、账号或旁人入镜时拍摄。
- [ ] 原始照片仅在受限本地目录，关闭自动云同步；文件名只用 P 编号和序号。
- [ ] 裁切或遮盖脸部、工牌、屏幕文本、环境标识；由第二人检查仍可识别的细节。
- [ ] 仅在 C/D 相应同意范围内展示；记录展示去向，不使用原始照。
- [ ] 去标识版核对完成后删除原始照片；最终材料只保留必要的去标识版和独立同意记录。
