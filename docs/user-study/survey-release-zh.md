# ApplyGuard 求职材料修改流程问卷（正式发放版）

版本：`FS-2026-10-02-v1` · 预计 3–5 分钟 · 目标：10–20 份符合筛选条件的回答

## 放在问卷首页的说明

这是一项软件工程课程项目的前期需求研究。我们想了解你目前如何针对岗位描述（JD）修改简历、核对经历证据和填写网申表单。问卷尚未测试 ApplyGuard 原型，没有标准答案。参与自愿，可跳过非筛选题或随时退出。请勿填写姓名、联系方式、学校/公司名称、真实简历内容、具体投递记录或账号信息。问卷不需要上传文件。回答仅以匿名编号汇总用于课程 Proposal、展示和报告；短句匿名引用另行征询同意。

### 同意与跳题（不计入 10 题）

- C0（单选，必答）：我已阅读上述说明，同意将匿名回答用于本课程研究：`同意` / `不同意`。选“不同意”立即结束，不记录后续题目。
- C1（单选，选答）：是否允许研究小组在课程材料中引用你的一句**已去标识化**原话：`允许` / `不允许`。拒绝不影响作答。

### 参与者筛选（不计入 10 题）

- S1（单选，必答）：目前学业阶段：`大四本科生` / `研究生（硕士或博士）` / `其他`。
- S2（多选，必答）：当前集中浏览或申请的岗位类型：`软件开发` / `AI/机器学习` / `数据分析/数据工程` / `其他岗位` / `目前没有集中申请`。若仅选后两项，结束。
- S3（单选，必答）：最近一个正常求职周浏览或申请的岗位数：`0–4` / `5–9` / `10–19` / `20 个及以上`。
- S4（单选，必答）：可用于求职材料的项目、科研、竞赛或实习经历有几段：`0–2` / `3–4` / `5–6` / `7 段及以上`。

只有 S1 为大四/研究生、S2 至少选一个目标岗位、S3 为 5 个及以上、S4 为 3 段及以上，才进入下面正式问卷。筛选失败应友好结束，不计入有效样本。平台若不能自动跳题，导出后按同一规则筛除并记录数量。

## 正式问卷：先问现状，再介绍概念

1. **过去四周，你针对不同 JD 修改简历的频率是？**（单选）`几乎每个岗位` / `多数岗位` / `少数岗位` / `完全没有`。选“完全没有”仍继续作答，可在后题选“不适用”。
2. **针对一个岗位修改一版简历，通常花多久？**（单选）`少于 5 分钟` / `5–15 分钟` / `16–30 分钟` / `超过 30 分钟` / `最近没有做过`。
3. **最近一次看到 JD 后，你实际做过哪些事？**（多选）`标出 JD 关键词或要求` / `对照已有简历或经历清单` / `决定保留或删除项目` / `改写 bullet/描述` / `检查指标或技能是否有依据` / `另存一个简历版本` / `把内容填进 ATS/网申表单` / `最近没有做过`。最后一项与其他项互斥。
4. **你实际用过哪些工具处理这些事？**（多选）`Word/在线文档` / `表格、笔记或 Notion` / `文件夹/网盘中的多个简历版本` / `ChatGPT、Claude 等通用 AI` / `简历修改或匹配专用工具` / `招聘网站/ATS` / `没有使用工具` / `其他（不写具体账号）`。没有使用工具与其他项互斥。
5. **当你要证明某段经历、技能或数字时，证据通常在哪里？**（单选）`集中保存，容易找到` / `分散在仓库、报告、笔记等位置，找起来较难` / `主要靠记忆或临时问人` / `通常没有可查证的材料` / `不确定`。
6. **使用 AI 修改求职材料时，遇到过“写了自己没做过、夸大成果或写错事实”的情况吗？**（单选）`从未使用 AI` / `使用过，没遇到` / `遇到过 1 次` / `遇到过多次` / `不确定是否准确`。
7. **以下哪些问题你亲身遇到过？**（多选）`不知道该选哪个项目` / `找不到某个 Claim 或数字的依据` / `相似内容重复` / `用了错误的简历版本` / `AI 改写不准确或过度包装` / `ATS 要求反复重填` / `ATS 信息与简历不一致` / `敏感或不确定的 ATS 问题难以回答` / `都没有`。最后一项与其他项互斥。

下面三题只询问你对一个**设想中的**工具的偏好：它能把简历内容连到经历证据、解释为何选择项目，并在缺少依据时提示用户；它不会代替用户提交申请。

8. **如果一条简历内容可以点开查看它来自哪段经历和哪些证据，这对你有多大帮助？**（单选）`1 完全没有帮助` / `2 帮助较小` / `3 说不清` / `4 比较有帮助` / `5 非常有帮助`。
9. **如果 JD 要求的技能在你的经历中找不到证据，系统最应该怎样做？**（单选）`直接写进简历` / `写出草稿但醒目标记并等我确认` / `只提示缺口，先让我补证据` / `禁止写入该 Claim` / `不确定`。
10. **哪些操作必须先由你确认？**（多选）`新增或加强某条经历表述` / `写入量化成果` / `删掉或调整项目顺序` / `填写普通 ATS 字段` / `填写敏感或不确定的 ATS 字段` / `最终提交申请` / `全部都不需要确认`。最后一项与其他项互斥。

选答开放题（不计入 10 题）：**你最担心这种工具犯什么具体错误，或哪个步骤最不合理？** 最多一句话；不要写可识别的人、公司、具体经历或链接。

## 建表设置与冻结检查（研究者使用，不展示给参与者）

- 各题按上面的单选/多选类型设置；C0、S1–S4 必答，正式 10 题允许跳过；单选不得强制默认答案。
- 关闭自动收集姓名/邮箱、登录要求、文件上传及可见的个人信息字段；若平台默认记录可识别日志，应在收集前检查设置并限制访问。
- 先以 1–2 位目标用户试填，记录耗时、歧义与修改。正式发放后固定版本，不在收集中途无记录地改题。
- 导出后按 S1–S4 筛选；不给每个人编造答案，也不把探索性小样本百分比说成总体结论。
- Q9 的“直接写进简历”和 Q10 的“全部都不需要确认”只用于了解偏好；无论回答如何，都不能放松项目的无证据 Claim 阻止/人工确认和不自动提交约束。
