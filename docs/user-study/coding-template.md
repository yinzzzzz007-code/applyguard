## Coding procedure

1. Redact accidental identifiers.
2. Attach one or more codes to concise evidence references, not invented summaries.
3. Record counterexamples and uncertainty.
4. Group recurring codes into tentative findings only after checking the underlying notes.
5. Send candidate findings to A for formal requirements, to C for failure cases, and to D for proposal-slide review.
