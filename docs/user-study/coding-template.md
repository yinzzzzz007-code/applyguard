> Start coding only after receiving consented, anonymized responses. Codes below refer to [the released Chinese survey](survey-release-zh.md) Q1–Q10 and the interview notes. They are an initial guide, not results. Do not use question numbers from the archived English draft.

| TRACEABILITY_VALUE | Perceived usefulness or limitation of claim-to-evidence links | `P__ Q8; interview` |  |

## Coding procedure

1. Redact accidental identifiers.
2. Attach one or more codes to concise evidence references, not invented summaries.
3. Record counterexamples and uncertainty.
4. Group recurring codes into tentative findings only after checking the underlying notes.
5. Send candidate findings to A for formal requirements, to C for failure cases, and to D for proposal-slide review.
