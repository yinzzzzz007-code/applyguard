# 问卷来源与使用边界

本次没有找到适合原样复制的“ApplyGuard Proposal 前需求发现标准问卷”。`survey-release-zh.md` 是基于项目目标自行编写的**形成性问卷**，不是经过信效度验证的量表，也不是 LL.me、ResumeGenAI、SUS 或 NASA-TLX 的官方中文版。

- [LL.me: Supporting Identity Work through Human-AI Alignment (CHI 2026)](https://doi.org/10.1145/3772318.3790890)：其原型使用后研究关注自我呈现的准确性、控制感、表达和一致性。启发本项目在**后续原型评估**中关注这些维度；当前问卷只问可追溯性的预期价值，不声称测出了真实使用后的准确性或控制感。
- [ResumeGenAI: Supporting Job Seekers with LLM-Driven Resume Feedback (CUI 2025)](https://doi.org/10.1145/3719160.3737622)：其前测问及简历修改经验、反馈和更新频率。启发本项目先问当前工作流程、耗时和工具，再介绍 ApplyGuard 概念。本文没有复用其完整问卷或数据。
- [NIST: Human-Centered Design Research Methods](https://www.nist.gov/itl/iad/human-centered-technologies/methodology)：支持结合问卷与半结构化访谈理解使用情境、需求和实际做法。
- [NASA Task Load Index 官方说明](https://www.nasa.gov/human-systems-integration-division/nasa-task-load-index-tlx/)：NASA-TLX 在具体任务之后评估主观工作负荷。若 D 在 Proposal 后做任务型实验，应使用官方说明和完整评分流程；本阶段不测 NASA-TLX。
- [University of Oregon: Photography in Research](https://research.uoregon.edu/manage/integrity-compliance/human-subjects-research/guidance-library/audio-video-photography)：照片可能含可识别信息，应事先明确拍摄、使用、保存和删除范围，并为照片设置独立同意选项。本项目按课程/学校要求执行，优先拍不露脸的过程照。

对外报告时写“问卷题目参考已有研究主题后为 ApplyGuard 自行设计”，不要写“采用了经验证的标准问卷”或把未来 SUS/NASA-TLX 的计划写成已取得的结果。
