使用 Playwright CLI，在 ApplyGuard 的隔离实例中创建虚构简历及虚构 Markdown 原件，审核并关联后测试；没有读取或上传用户真实简历。

- 岗位预检查显示 2/2 条要求有已核验证据支持。
- 由收藏岗位进入 `/jd?job=...`，能自动载入本机草稿并保留岗位版本。
- 离线工作流 → 证据匹配（2 条强匹配）→ 简历审查 → 陈述核验（已核验）→ ATS 模拟 → 敏感字段本人确认 → 人工确认 → 本机模拟确认成功。
- 自动测试同时验证无原件、证据撤销与过期岗位不会因人工确认而提升支持状态。
- 人工确认材料显示收藏岗位名称、公司和版本；历史摘要保存相同岗位编号及当次版本，明确标为“模拟确认，未投递”。
- 旧草稿的项目缺少可选“角色”等字段时，确认页显示“未填写”，不再报错。
- 桌面宽度 1200 与手机宽度 390 检查通过；岗位页手机视口的文档宽度为 375，不出现横向溢出。最终确认页复验无新增浏览器运行错误。

本次未调用付费模型、未真实投递，也未做所有招聘源的可用性或岗位匹配准确率评测。外部雷达独立运行，其定时采集、论文热度、个人方向评分和模型摘要没有嵌入 ApplyGuard。岗位同步是用户主动读取/重导入，不是自动后台同步。模型效果需要用户另行选择模型路径并单独评估。
