# 2026-11-13 歧义扩展与截图简历实测

真实 Gemini 在合成案例中曾把一项指标的“约”错误加到另一项，措辞审核还判定等价；本轮在共享数值保护层修复，并保留修复前后记录。用户给出的截图转换成图片型 PDF 后，现有简历导入器对 4/4 选中样例返回 422；本地 OCR 文字层可让 4/4 进入导入流程，但仍有字段漏提。

## 范围和隐私

- 基线为 `11.13` 分支提交 `afa481a`，本轮修复和 CLI 是其后的本地工作，未推送。
- 图片按用户指定的 14 张转换；第 8、9 张另做两页合并版。每个 PDF 保留 JPEG 原始数据，逐页 SHA-256 检查一致，抽样渲染核对。原图 PDF 是图片型文件，没有可复制文字层。
- 本地选图 3、6、7、14 的中英文简历截图进行 OCR 和导入。截图、PDF、OCR 正文及实测输出放 `output/`，由 Git 忽略；模型测试只发送四条去标识化的短经历片段及合成案例，不发送完整简历或联系方式。
- 样本来自用户提供的截图；不判断截图所述经历真伪，也没有独立证明材料。真实模型测试只覆盖措辞审核，未声称完整的原件检索、原子核验和最终导出均已在这些简历上通过。

## 已复现并修复的近似数值归属

原句：`对甲方案，延迟约下降11%；对乙方案下降18%。` 模型先发现甲乙错配，但修复为 `对甲方案，延迟约下降11%；对乙方案，延迟约下降18%。` 并判断等价。第二个 `约` 改变了 18% 的确定程度。

`fact_lock.py` 原有近似数值检查只检测旧近似丢失，没有检测既有精确数值被新增近似。现在同时检查两方向，并只对双方出现的明确数值标记；无法可靠解析的说法仍交给语义与证据审核。新增中英文、句序调整、增加／删除近似和模型错误修复的回归用例。该保守规则可能增加误拦，需持续用新语料检查。

```powershell

# 按顺序转换 JPEG，各自生成 PDF，另外合并第 1、2 张
..\.venv\Scripts\python.exe scripts/images_to_resume_pdfs.py .\a.jpg .\b.jpg --output output/pdf/new-run --merge 1 2
```

真实模型 CLI 使用配置的模型与地址，密钥从环境变量或隐藏输入取得；`PASS` 表示所选样本无已识别问题，`FAIL`／`INCOMPLETE` 退出码 1，存在需人工审核的模型修复时为 `REQUIRES_REVIEW`、退出码 2。模型修复不能自动按正确计数。原本首次运行的实测文件没有总状态字段，以上分类依据逐行结果和人工核对。

后续优先：① 在简历导入增加明确的本地 OCR 选项，按页识别并显示失败／需要复核状态；混合文字和图片页不得静默遗漏，单页失败不能当成完整成功。② 扩展中英教育经历分组，支持校名不在行首、英文校名和同一简历多条教育经历；用新的匿名合成与经许可样本验证。③ 扩充职责／环境／对象归属的新写法与独立标注数据，分别测模型初始错改、修复、最终错放及误拦，不把规则压力集视为真实发生率。
