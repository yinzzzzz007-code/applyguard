# 经历自动选入和补选验证（2026-11-23）

问题：原选择器以材料已核验为选入前提，因此目标岗位匹配和事实核验被绑在一起，经历库有内容时正文仍可能为空。

现在：岗位分析完成后，空白审查草稿按现有语义匹配分或关键词覆盖选最多 3 条经历进入待核验正文。没有有效匹配时显示原因和补选入口。自动选入不代表材料支持；已有正文和编辑保持，项目加入后仍需独立核验。

正文每条可以直接移除，撤销可恢复；移除从申请正文生效，不删除经历库原条目。下方可搜索、按类型筛选、下拉或展开列表补选；已在正文中的经历按 ID 或相同文本隐藏。保存初始化状态避免刷新时重新加回已删除项。

云朵默认收起，点击云朵或页头引导后针对当前状态显示；有禁用项可点原因引导，不会因鼠标经过反复弹出。补选、删除会使原核验过期。
