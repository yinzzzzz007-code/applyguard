# 通用新手引导短片

按用户要求直接替换原「个人项目放映」内容，保留 kinetic-reel 的画面、粒子、转场、配乐与播放控件，不保留个人项目入口。

所有人使用同一个静态内容源 `frontend/src/motion/onboarding.ts`。该模块不读取个人简历、不请求草稿 API、不调用模型，也不会自动标记工作流完成。

24 秒时间轴：片头 0–3 秒；建立经历 3–7.5 秒；补充依据 7.5–12 秒；准备岗位 12–16.5 秒；核对保存 16.5–21 秒；收尾 21–24 秒。每个阶段均提供当前动作、原因与完成标志；完整说明折叠在播放器下方。唯一主要按钮为「开始准备我的申请」，进入现有简历识别页面。

引导保留原材料归属与陈述支持的区分、缺证据先处理、人工确认不能绕过事实问题、旧文字恢复后重新核验，以及最终网站提交由本人完成。首次使用不以其他工具或 Agent 为前提；本轮没有实现或扩充 Agent 连接功能。

构建、lint、24 项 smoke/单元测试通过，lint 保留原有三条警告；原时间轴测试已扩展覆盖四个阶段。Impeccable detect 返回 []。个人资料、核验逻辑、页面切换、版本与材料接口均未修改。宽屏电影镜头、四个章节切换及开始按钮在本地应用中检查。
