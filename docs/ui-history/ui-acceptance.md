# UI 验收标准

1. 导入：键盘可以到达文件输入；PDF / 5MB / 扫描件限制可见；本地与模型方式的材料发送范围明确；成功、失败、处理中和未选择的操作状态一致。
2. 编辑：标题、原稿、来源和主要操作可在短时间内找到；长陈述不截掉事实；来源详情可以点击和键盘展开。
3. 核验：所有统计来自当前数据；文字和颜色共同表达状态；待复核与阻断不能冒充通过；失败不保留旧的可导出结果。
4. 历史：每次采用建议可保留前后文字；恢复历史后必须重核验；清除浏览器存储的影响有说明。
5. 响应式：390 / 768 / 1440px 检查页面级横向溢出、导航开关、主要操作触摸区域、长文件名和长句。手机不出现固定桌面侧栏。
6. 可访问性：可见焦点、语义按钮、表单标签、状态文字、减少动画支持。正文色与背景对比至少 4.5:1；状态不能只靠颜色。全站第三方读屏验收另外安排。
7. 回归：build / smoke 通过；样式修改不改变 SAG 输入签名、版本失效、拒绝陈述、人工确认和导出门禁。

本轮执行范围与未覆盖项见 ui-design-process.md；验收标准不是全部已完成测试的声明。
