# 第三轮 UI / Kinetic reel 验证

用户明确指出第一版卡片式动画缺少创意，随后以实际 kinetic-reel 模板核心替换。保留主界面视觉系统，只在页尾电影区域使用其动态图形语法。

## 已完成

- 24 秒时间轴，真实项目名称、职责、日期和原文；最多三个项目，首项 8 秒，其他各 5 秒；开场和收尾各 3 秒。1/2 项会重新分配时长。
- 逐字动画、描边回声、三维粒子地形、蓝紫流体字形、节点连接；圆形展开 / 推移 / 擦除 / 百叶窗。原文字体位置裁切，避免入场时撞上 HUD。
- 本机字体与配乐，默认静音；没有外部字体请求、没有模型请求。音轨已在浏览器实际加载，duration=24、readyState=4，可播放；循环结束回到片头。
- 暂停、进度、章节选择、原文展开、收起；离屏计时停止且卸载 Canvas，重新进入恢复。实际观测离屏时进度保持 0.34s，Canvas 卸载，播放为 false。
- 从岗位页切换经历库后仍能使用放映，控制台无新的 warning/error；内容相同的表单加载不会重复销毁同一 Canvas 上的 WebGL 上下文。
- 宽屏 1910 CSS px 已逐镜看图；390 CSS px DOM 测量无横向溢出，使用竖版。窄屏截图工具出现缩放/空白采集问题，因此未将其当作可靠视觉金图。此前 582px 下已看到完整竖版画面。
- 24 项 smoke / 单元测试通过，包含原有核验/复制保护；新增五项检查原文、Unicode、24 秒循环、暂停与可视性条件。build 成功；lint 只有原有三条警告。
- Impeccable detect 一次检查返回 []；taste 源码检查 0 FAIL、1 WARN（真实时钟补零）。新增 rendererReady / 稳定项目值身份修复后通过构建与浏览器检查。

## 看图循环的具体修正

初版暴露了进度控件的辅助标签，暂停时标题半透明，镜头高度不稳定；已修正并在用户反馈后替换整个卡片舞台。电影版逐镜修正了长原文跌入 HUD、孤行标点、缺少限定词的关键词展示、字体静态路径、首帧准备和上下文生命周期。电影中的 01 是真实章节序号，HUD / 窄体英文字 / 局部黑场属于用户明确指定的 kinetic-reel 风格。

## 限制

这是应用内实时动画，未走 Puppeteer / ffmpeg 离线管线，未输出 MP4。没有 Safari、真实手机、完整屏幕阅读器或用户研究验证，未作音频人工听感评审。系统减少动态效果分支已实现并测试纯条件逻辑，本轮未通过系统设置做实际偏好切换。原文展示不是独立事实核验，也不会解锁原有的核验或导出门槛。PRODUCT.md 的旧格式未在此任务中迁移。
