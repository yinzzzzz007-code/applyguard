# 真实简历集成复查（2026-11-23）

使用一份经授权的真实简历，在独立工作区检验 OCR 导入、岗位匹配、材料核验、严格导出和个人稿导出。编辑一处名次和分母后，浏览器保留编辑并重新核验。单项有据的奖项严格导出返回 HTTP 200，含证据不足陈述的完整草稿返回 HTTP 422。复测也遇到上游模型 HTTP 503。

15 份 PDF 均完成本地导入。另用 2,800 条合成歧义配对检查规则层。导入成功率与文字识别准确率分别评估，规则测试也不代表实际模型漏检率。原始文件、引文和逐次输出保存在授权测试机上。

复查入口见 [项目地图](architecture-2026-11-13.md) 和 [演示工作区验收](testing-report-2026-11-24-recording.md)。
