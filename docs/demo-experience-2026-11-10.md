# 演示体验优化 · 2026-11-10

本轮基于 `code/applyguard` 当前工作树，保留已有的证据字段核对等未提交改动；只优化前端加载、连接提示和预录演示流程。

## 变化

- 页面按路由加载，保留导航和上下文；加载中有提示，页面异常时提供刷新入口并可继续切换侧栏。
- 顶部实际检查本地服务：5 秒超时、15 秒间隔，隐藏页面不主动轮询；校验服务标识，避免把 HTML 或其他服务当成连接成功。此状态不代表模型可用。
- 首页、帮助页新增错改阻断与超时回退入口。切换时检查未保存经历和暂存文字，提示后才清空当前编辑。
- 预录与错误场景不再读取个人后端草稿。预录岗位为只读，匹配页使用录制原文，避免与输入框的其他岗位混用。
- 旧预录缺少新版逐句核验字段时，审核页明确显示“预录结果：已阻断”；编辑后仍显示待核验。该标签仅用于展示，不改变导出或复制权限。

## 验证

- `npm run build` 通过。主入口 JS 从 545.15 KB 降至 303.94 KB（gzip 从 169.51 KB 降至 97.78 KB）。这是构建产物体积，不是实测加载时间；首次进入首页仍需加载首页及其共享依赖。
- `npm run smoke`：基础 smoke 通过，39 项测试通过。新增后端隔离、异常健康响应和预录编辑后失效的回归。
- `npm run lint` 退出码 0；仍有既有文件的 6 条警告，涉及 Hook、ref、热更新及转义。
- 浏览器在后端未启动时走通：首页 → 错改阻断 → 加载演示结果 → 证据匹配 → 简历审查；确认岗位原文及两条“预录结果：已阻断”。检查过窄窗口审核布局。
- `git diff --check` 通过。

未调用付费模型，未进行真实申请提交，也未重新评测模型质量。本轮未修改后端，未运行后端全套测试。超时回退样例通过客户端自动化检查，未逐页人工走完。

## 演示路径

启动前端后打开首页，点击“体验错改阻断”，再点击“加载演示结果”，依次进入证据匹配与简历审查。顶部菜单可返回“连接本地后端”。本地模式需要另行启动后端；预录演示仅需前端服务。
