# SAG 默认启用与高风险模型分流：测试报告

日期：2026-11-03（北京时间）。分支：`feature/career-radar-integration-20261103`。所有测试使用虚构材料或模型替身；没有调用付费模型，也没有真人标注。

## 实现与边界

- 服务端默认 `sag_atomic`，客户端传 `off` 或 `sag` 不得降级；管理员显式配置 `off` 才能运行旧离线演示。缺密钥、证据或模型失败保留不可自动导出的状态。前端的润色与复核入口统一请求 `sag_atomic`。
- 默认轻量模型仍由 `APPLYGUARD_AI_MODEL` 指定。仅当管理员配置 `APPLYGUARD_STRONG_AI_MODEL`，且润色差异触及数字、职责、技术、否定、部署等风险词时，才对提案发起第二次原子核验。第二次判断与第一次均为支持，且原信息保留检查通过，建议才可能采用；第二次失败则恢复原文。它不改变证据来源版本检查、人工确认或导出门槛。
- 这是确定性风险路由与模型替身的机制测试，不证明强模型更准确，也不证明 SAG 检索、原子核验或本次分流降低了真实幻觉率。风险词表可能漏掉未列出的表达；原子核验仍需检查所有提案。来源冲突但没有润色差异的句子继续按既有原子核验待复核，不触发强模型。
